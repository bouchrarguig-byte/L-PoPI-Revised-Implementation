# Publication notice for the raw PUF data

The `raw/` directory contains experimental SRAM power-up responses from six research boards. Publishing these files makes the observed PUF responses permanently public. These boards therefore should not later be treated as production devices whose SRAM-PUF response is secret.

No board MAC addresses are included in this public package. Local absolute workstation paths in collector logs have been replaced with `/REDACTED_LOCAL_PATH`; the recorded capture data, capture indices, protocol metadata, retry events, and statistics are otherwise preserved.
